# ADR-0034: /ask の応答を実行者本人限定(ephemeral)にする

- ステータス: proposed
- 日付: 2026-08-26
- 関連: design.md §6.2(処理フロー step 1)・ADR-0025 D4(/stats は ephemeral)・ADR-0018(可視性ゲート)

## 背景

design.md §6.2 step 1 は「受信即時に『調べています…』を**エフェメラルでなく**スレッド返信で投稿
(検索過程と回答を後から全員が参照できるようにする)」とし、実装もそのとおり公開返信だった
(`handleAsk` の `deferReply()` に伴い、質問エコー・処理中表示・回答・出典・エラー・👍👎 が
チャンネル全員に見える)。

本番運用で「質問と回答が全員に見える」ことが質問の心理的ハードルになるという運用判断があり、
**/ask の応答一式を実行者本人にだけ表示する**よう変更する(2026-08-26 ユーザー決定)。
ナレッジの共有は、回答の出典である knowledge-base 本体と、各自が同じ質問を /ask できることで担保する
(回答はその場の 1 回きりの表示であり、共有の正典はもともと KB 側にある)。

## 決定

- **D1: /ask の全応答を ephemeral にする。** 対象 = 質問エコー(コマンド実行の表示)・「考え中」
  プレースホルダ・回答本文(分割チャンク含む)・出典・NOT_FOUND・タイムアウト・エラー通知・
  送信失敗通知・👍👎 ボタン・ボタン操作の ack。deny(チャンネル外)・rate-limit・/stats は従来から
  ephemeral(ADR-0025 D4)で変更なし。
- **D2: エフェメラル化は `deferReply({ flags: MessageFlags.Ephemeral })` の 1 点で行い、
  `followUp` には毎回 flags を付す。** discord.js v14 では `editReply` は defer のエフェメラル性を
  継承する(オプションに flags/ephemeral が存在しない)が、`followUp` は素の webhook 送信で
  継承しない。続きチャンクと部分失敗通知は `deliverAnswer` の配送 seam を通るため、`handleAsk` の
  アダプタ側で `{ ...m, flags: MessageFlags.Ephemeral }` を一括付与する(seam・`deliverAnswer` 本体は
  不変)。新規箇所は非推奨の `ephemeral: true` でなく `flags: MessageFlags.Ephemeral` を使う
  (既存箇所の一括移行は別タスク)。
- **D3: 👍👎 ボタンは /ask 実行者本人のみ操作可とする。** `queries.discord_user_id`(記録済み)と
  押下者を照合し、不一致は ephemeral で拒否する。ephemeral メッセージは本人にしか配信されず
  他者はコンポーネント操作を発生させられない(フレームワーク保証)が、エフェメラル化以前の
  公開回答にはボタンが残り続けるため、store 照合を防御の重畳として置く。record が見つからない
  queryId は従来どおり処理する(挙動互換)。

## 却下した代替案

- **editReply / 後続メッセージ側での非公開化**: Discord API 上不可能(エフェメラル性は初回応答
  = defer の時点で確定し、後から変更できない)。
- **公開のまま「スレッドに畳む」**: 見える範囲は変わらず、目的(本人限定)を満たさない。
- **ボタンの本人検証を省略(ephemeral の枠組み保証のみに依存)**: 新規メッセージには十分だが、
  過去の公開回答のボタンが残るため照合を採用。

## 影響・トレードオフ

- 他メンバーが他人の Q&A から偶発的に学ぶ導線は消える。代替 = KB(正典)+ 各自の /ask。
- ephemeral メッセージは Discord 上に永続せず(クライアント再起動等で消える)、後から
  参照できない。質問・回答・評価は従来どおり bot.db の `queries` に記録され、👎/未回答は
  フライホイール(質問キュー)に載るため、改善ループは不変。
- 利用ガイド(knowledge-base の正典)§1 に「回答は本人にだけ表示される」旨を追記する。

> 追記(2026-10-07): 回答が消えて後から参照できない点への対応として、本人の明示操作に限り
> 「📌 残す」(本人 DM へ保存)と「📢 共有」(確認画面を経て共有チャンネルへ公開・Discord 引用付きの回答は不可・
> 1 回答 1 回)を置く。本 ADR の例外として ADR-0040 に記録する。
